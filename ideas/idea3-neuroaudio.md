# idea3 — state-encoded audio: mixes engineered for brain-states (frozen 2026-09-10)

Status: proposed (owner's raw brief, banked verbatim-ish). Awaiting bout.

## Problem

Knowledge workers listen all day while working, but the audio is
state-agnostic: gamma blasts at hour 0, same playlist for running and
writing, no cooldown. State-dependent memory is real (Godden & Baddeley
divers; Smith meta-analyses ≈ modest effects): context cues recall. Music
moves arousal/mood reliably. Binaural-beats performance claims are
WEAK/MIXED (EEG entrainment measurable; cognitive transfer unproven —
do not sell what isn't shown).

## Mechanism

Adaptive focus mixes: per-activity target states (run/ideate/focus-down),
novelty slider, mood themes, engineered arcs (buildup → peaks → cooldown
over 60-min or 20-min bursts), shareable, preference-learning over time.
Product carries on ritual + preference + arousal shaping even where
entrainment claims don't. Screen-recorded workdays (ScreenPipe/ActivityWatch
layer) close the loop: rhythm in, mix out.

## Falsifiable predictions

- [ ] A 2-week n=1 crossover (engineered arcs vs shuffled same tracks)
  shows ≥15% more self-reported deep-work minutes on engineered days.
- [ ] Novelty-slider position predicts skip rate (higher novelty → more
  skips when arousal already high).
- [ ] Cooldown endings beat hard stops on next-session start latency.

## Non-goals

No medical claims. No binaural-beats efficacy promises. No cloud audio
pipelines (local-first like the capture layer).

## Verification plan

Bout lanes build mix-engine prototypes against a fixed listener-profile
fixture + scoring rubric (arc shape, novelty control, share format);
validator checks structure, not taste. Real validation needs the n=1 trial
above (human lane).
