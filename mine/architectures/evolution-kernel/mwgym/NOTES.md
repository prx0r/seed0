## Development

### Installation

First, install the dependencies:
```bash
npm install
```

Or using npm ci for a clean install:
```bash
npm ci
```

### Type Checking

Run type checking with:
```bash
npm run typecheck
```


Run tests with:
```bash
npm test
```

## Python Integration

python3 -m pytest
