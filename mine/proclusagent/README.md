# proclusagent — old structures made agentic

> Two thousand years of structured thought — propositions, verses, maps,
> guardrails — are already agent-shaped. This repo turns them into running
> systems: verse ledgers agents claim and fill, research maps that constrain
> commentary, dossiers that brief agents per text, all fenced by doctrinal
> guardrails no model may flatten.

## The thesis in one diagram

```text
old structure                          agentic structure
─────────────────                      ──────────────────
proposition chain (Elements)     ──►    scene graph (pr01–pr20, addressable, renderable)
verse corpus (6,903 Tantraloka)  ──►    claim ledger (OPEN → claimed → verified)
research map (37 āhnikas)        ──►    constraint set (truth conditions per chapter)
dossier (concepts + rules)       ──►    agent system prompt + comparison guardrails
commentary tradition             ──►    multi-agent debate with provenance
```

## Rules (binding)

1. **Provenance or it didn't happen**: every claim cites verse/scene + source hash.
2. **Guardrails from the dossiers**: no flattening (One≠Brahman, procession≠creation).
3. **Truth conditions per chapter** from the master map — commentary states what would falsify it.
4. **Ledger discipline**: OPEN → claimed (one agent) → verified (second agent or human). Never two writers on one verse.
5. **Secrets in vaults, never in the tree.** Same house rules as `prx0r/cmail` (`AGENTS.md` there).
